# OpenEgiz Helm Charts

Branch-scoped Helm chart and Grafana plugin artifacts for the OpenEgiz rebrand work.

Use this repository URL while the work is under review:

```bash
helm repo add openegiz https://raw.githubusercontent.com/openegiz/helm-charts/codex/bootstrap-openegiz-helm-charts
helm repo update
```

Artifacts in this branch are intentionally published outside `main`.
